# Skills

Coloque aqui as skills do plugin, uma pasta por skill:

```
skills/
└── nome-da-skill/
    ├── SKILL.md        ← obrigatório (frontmatter com name e description)
    └── ...             ← scripts, templates, checklists de apoio
```

Depois de adicionar, suba a `version` em `.claude-plugin/plugin.json` e no `marketplace.json`.
